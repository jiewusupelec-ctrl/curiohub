# 好奇心补给站 · 小小知识电台 — 微信小程序发布与上线完整指南

本目录（`miniprogram/`）是 **“好奇心补给站 · 小小知识电台”** 的完整生产级原生微信小程序版本（支持微信锁屏与切后台连续播放、11 个主题动态卡通舞台、女声晓晓 / 男声云希无损切换、长短搭配约 20 分钟且严格 ≤ 22 分钟、每日 5 次零重复换批，以及从 GitHub Pages 自动拉取每日最新故事与音频）。

---

## 一、目录结构与架构说明

```text
curiohub/
├── project.config.json              # 仓库根目录微信开发者工具配置（自动指向 miniprogram/）
└── miniprogram/
    ├── project.config.json          # 小程序目录独立配置（支持直接导入 miniprogram/ 目录）
    ├── app.json                     # 页面路由、浅蓝天空导航栏、requiredBackgroundModes: ["audio"]
    ├── app.js                       # 全局配置与音频会话初始化
    ├── app.wxss                     # 全局浅蓝天空背景与卡片样式
    ├── sitemap.json                 # 微信索引规则
    ├── data/
    │   └── bundled-stories.js       # 11 个主题 SVG 矢量卡通插画 Data URI + 88 条离线精选故事兜底库
    ├── utils/
    │   └── audio.js                 # 基于 wx.getBackgroundAudioManager() 的后台/锁屏音频播放管理服务
    └── pages/
        ├── index/                   # 主播放器页面（动态插画舞台、进度条拖拽、男女声切换、每日 5 次换批、知识地图）
        │   ├── index.wxml
        │   ├── index.wxss
        │   ├── index.js
        │   └── index.json
        └── about/                   # 关于与说明页（10 岁儿童内容准则、11 个主题来源、隐私保护与历史清理）
            ├── about.wxml
            ├── about.wxss
            ├── about.js
            └── about.json
```

### 核心特性
1. **自动同步每日新故事 + 离线兜底**：
   - 小程序启动时先秒开加载 `data/bundled-stories.js` 内置故事库（零等待），同时在后台请求：
     - `https://jiewusupelec-ctrl.github.io/curiohub/stories-v2.json`
     - `https://jiewusupelec-ctrl.github.io/curiohub/session-meta.json`
   - 当 GitHub Actions 每天两次（UTC `22:30` 与 `08:30`）自动更新故事与双声线 MP3 后，小程序无需重新发版即可自动获取当天最新故事与音频！
2. **原生锁屏与后台伴听（`wx.getBackgroundAudioManager()`）**：
   - 已在 `app.json` 中配置 `"requiredBackgroundModes": ["audio"]`。
   - 当孩子收听时，即使手机锁屏、熄屏或切换到其他 App，音频也会继续流畅播放，并在系统锁屏界面显示当前故事标题、主题及上一首/下一首控制按钮。
3. **每日 5 次不重样换批 + 长短搭配 ≤ 22 分钟**：
   - 每篇故事根据内容自然分为**短篇快讯（40–65 秒）**、**中篇故事（75–115 秒）**和**深度长篇（125–160 秒）**。
   - 每次自动组合约 **20 分钟**（硬上限严格 **≤ 22 分钟 / 1320 秒**）的播放单。
   - 每日允许点击“换一批” **5 次**（共 6 批不重样内容），并通过微信本地 `Storage` 记录最近 14 天已听故事 ID，跨天也不重复。

## 二、四步上线流程（从注册到发布审核）

### 第一步：注册微信小程序账号并获取 AppID

1. 打开微信公众平台官网：[https://mp.weixin.qq.com/](https://mp.weixin.qq.com/)
2. 点击右上角 **“立即注册”** → 选择 **“小程序”**。
   - **主体类型建议**：个人主体或企业主体均可（本小程序无付费虚拟商品交易，纯科普工具/内容伴听，个人主体即可快速注册）。
3. 激活邮箱并完成管理员微信扫码实名认证后，登录小程序后台。
4. 在左侧菜单点击 **“开发” → “开发管理” → “开发设置”**，复制你的 **AppID(小程序ID)**（形如 `wx1234567890abcdef`）。

---

### 第二步：配置服务器合法域名白名单（关键步骤！）

小程序在线拉取每日最新 `stories-v2.json` 和播放 `audio/clips/{female,male}/*.mp3` 音频，需要将 GitHub Pages 域名加入合法域名列表：

1. 登录 [mp.weixin.qq.com](https://mp.weixin.qq.com/) → **开发管理** → **开发设置** → 向下滚动找到 **“服务器域名”**。
2. 点击 **“修改”**，填入以下 HTTPS 域名：
   - **request 合法域名**：
     ```text
     https://jiewusupelec-ctrl.github.io
     ```
   - **downloadFile 合法域名**：
     ```text
     https://jiewusupelec-ctrl.github.io
     ```
3. 点击保存并提交。
   - *提示*：在本地微信开发者工具调试阶段，如尚未配置域名，可在开发者工具右上角 **“详情” → “本地设置”** 中勾选 **“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”** 即可立即播放测试。

---

### 第三步：使用微信开发者工具导入与真机扫码预览

1. 下载并安装官方 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 打开微信开发者工具 → 选择 **“小程序” → “导入”**：
   - **项目目录**：既可以选择本仓库根目录 `curiohub/`，也可以直接选择 `curiohub/miniprogram/` 目录。
   - **AppID**：填入你在第一步获取的真实 AppID（并将 `project.config.json` 中的 `"appid": "wx_placeholder_appid"` 替换为你的真实 AppID）。
   - **后端服务**：选择 **“不使用云服务”**。
3. 导入后，模拟器将立即显示浅蓝天空背景的 **“好奇心补给站 · 小小知识电台”** 界面：
   - 点击播放按钮测试女声（晓晓）/ 男声（云希）切换；
   - 点击 **“换一批”** 验证 `今日还可切换 5 / 5 次` 倒扣与不重样故事组合；
   - 点击 **“11 个主题”** 标签验证顶部卡通插画即时切换。
4. 点击开发者工具顶部工具栏的 **“预览”** 按钮，用手机微信扫描生成的二维码，即可在真机上体验（包括锁屏后台播放效果）。

---

### 第四步：上传代码与提交微信审核指南

在微信开发者工具顶部点击 **“上传”**（填写版本号如 `1.0.0`，项目备注如 `好奇心补给站儿童科普电台初版发布`），然后回到 [mp.weixin.qq.com](https://mp.weixin.qq.com/) → **“管理” → “版本管理”**，在“开发版本”旁点击 **“提交审核”**。

#### 1. 服务类目选择建议
在 **“设置” → “基本设置” → “服务类目”** 中：
- **个人主体推荐类目**：
  - `工具` → `信息查询` 或 `工具` → `效率`
  - `教育` → `在线教育` / `教育信息服务`（无需前置审批资质的子项）
- **企业主体可选类目**：
  - `教育` → `教育信息服务` 或 `文娱` → `资讯`

#### 2. 后台音频接口（`requiredBackgroundModes: ["audio"]`）审核说明模板
由于 `app.json` 声明了 `"requiredBackgroundModes": ["audio"]`，提审时如微信审核页提示填写后台音频使用场景说明，可直接复制以下说明：

> **后台音频使用说明**：
> 本小程序为面向儿童与亲子家庭的每日 20 分钟科普知识音频伴听工具（“好奇心补给站 · 小小知识电台”）。为保护儿童视力、避免孩子在收听科普故事时长时间盯着手机屏幕，小程序调用 `wx.getBackgroundAudioManager()` 实现手机锁屏及切后台时的连续音频播报功能。

#### 3. 用户隐私保护指引（《小程序用户隐私保护指引》填写模板）
在提审环节配置 **“用户隐私保护指引”** 时：
- 选择 **“本小程序未收集任何用户个人隐私信息”**（或仅声明使用本地存储缓存收听进度）。
- 如需补充文字说明，可填写：
  > 本小程序不设账号注册与登录，不收集用户的姓名、手机号、位置、相册、通讯录或设备识别码等任何个人信息。小程序仅利用设备本地缓存（`wx.setStorageSync`）保存当日剩余“换一批”次数与已收听故事编号，用于为您过滤已听过的故事。
